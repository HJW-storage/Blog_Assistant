# 네이버 블로그 초안 도우미 (프로토타입)

C#/.NET 8 WPF로 만든 데스크톱(.exe) 프로토타입입니다.
기존에 써둔 블로그 글의 문체를 분석해서, 비슷한 톤으로 새 글 초안을 AI가 작성해줍니다.

| 요구사항 | 구현 방식 |
|---|---|
| 기존 글과 비슷한 포맷의 초안 생성 | 블로그 URL 자동 수집 또는 기존 글(.txt) 업로드 → 규칙 기반 문체 분석(+선택적 AI 심층 분석) → Groq API 호출 시 프롬프트에 포함 |
| .exe로 실행되는 UI | WPF (.NET 8) 데스크톱 앱, `dotnet build`로 .exe 생성 |
| AI 모델 선택 | 모델명을 코드에 하드코딩하지 않고, Groq 계정에서 실시간으로 사용 가능한 모델 목록을 조회해 드롭다운으로 선택. 블로그 글쓰기에 적합한 모델을 자동으로 추천 표시 |
| 임시저장 | **반자동 방식**입니다. 아래 "왜 완전 자동화하지 않았나" 참고 |

## 실행 방법 (Windows, .NET 8 SDK 필요)

```bash
cd NaverBlogDraftAssistant
dotnet build
dotnet run --project NaverBlogDraftAssistant
```

Visual Studio에서는 `NaverBlogDraftAssistant.sln`을 열어서 F5로 실행하면 됩니다.
배포용 .exe가 필요하면:

```bash
dotnet publish NaverBlogDraftAssistant -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## 사용 흐름

1. **탭 1 — 기존 글 스타일 학습**: 두 가지 방법 중 하나를 선택합니다.
   - 방법 1 (권장): 네이버 블로그 URL만 입력 → 앱이 RSS/게시글 목록을 순회하며 본문을 자동 수집
   - 방법 2: 기존에 써둔 글을 `.txt`로 저장해두고 (제목 없이 본문만) 여러 개 선택
   - "스타일 분석하기" 클릭 → 문단 길이, 소제목 사용, 어투(존댓말/평어), 이모지·감성 표현 빈도 등을 규칙 기반으로 분석
   - 선택적으로 "AI 문체 심층 분석"을 누르면 실제 글 샘플을 AI에게 분석시켜 자연어 지침을 추가로 뽑아냄
2. **탭 2 — 초안 생성**: 제목과 대략적인 개요/키워드 입력 → "초안 생성" 클릭 → 앞서 학습한 스타일을 반영해 AI가 본문 초안 작성. "키워드 제안 받기"로 제목 기반 키워드/소제목 아이디어도 받을 수 있음
3. **탭 3 — 네이버로 내보내기**: "네이버용 서식으로 클립보드에 복사" → 네이버 블로그 글쓰기 페이지 열기 → 본문에 붙여넣기(Ctrl+V) → **사용자가 직접 '임시저장' 클릭**

상단의 **Groq API 키**(`https://console.groq.com`에서 무료 발급)를 입력해야 스타일 심층 분석/초안 생성/키워드 제안 기능이 동작합니다.
"모델 목록 불러오기"를 누르면 계정에서 사용 가능한 모델이 드롭다운에 채워지고, 블로그 글쓰기에 적합한 모델이 추천으로 표시됩니다.

## 왜 "임시저장"을 완전 자동화하지 않았나

네이버 블로그는 과거 외부 프로그램용 글쓰기 API(metaWeblog/XML-RPC)를 제공했지만
이용약관·게시물 운영정책 위반 소지로 이미 종료했고, 현재는 공식 "글쓰기/임시저장" API가 없습니다.

이 상태에서 완전 자동화를 하려면 실제 웹 에디터 화면을 프로그램이 대신 조작하는
매크로/브라우저 자동화 방식을 써야 하는데, 이는 네이버의 자동화 프로그램 사용 제한
정책과 충돌해 **계정 정지 위험**이 있습니다.

그래서 이 프로토타입은:
- 스타일 분석 + 초안 작성까지는 완전 자동화하고,
- 마지막 "임시저장" 클릭 한 번만 사용자가 직접 하도록 설계했습니다.

이렇게 하면 번거로움은 거의 없이 계정 리스크 없는 형태로 요구사항을 최대한 충족할 수 있습니다.

## 참고: 만약 워드프레스를 함께 쓰신다면

워드프레스는 공식 REST API(`/wp-json/wp/v2/posts`, `status: draft`)를 제공해서
"임시저장까지 완전 자동화"가 이용약관 문제 없이 가능합니다. 필요하시면 이 부분만
추가하는 것도 어렵지 않습니다.

## 폴더 구조

```
NaverBlogDraftAssistant/
  NaverBlogDraftAssistant.sln
  NaverBlogDraftAssistant/
    MainWindow.xaml(.cs)      UI(모델 선택 드롭다운 포함) 및 전체 흐름 제어
    Models/
      StyleProfile.cs         스타일 분석 결과 모델
      ImageModels.cs          이미지/배치 추천 모델 (현재 UI 비활성화 상태)
    Services/
      NaverBlogScraper.cs     블로그 URL만으로 게시글 본문 자동 수집
      StyleAnalyzer.cs        기존 글 텍스트 통계 분석
      GroqApiService.cs       Groq API 호출 (모델 목록 조회 / 초안 생성 / AI 문체 분석 / 키워드 제안)
      DraftExporter.cs        초안을 네이버 붙여넣기용 HTML로 변환
      HtmlClipboardHelper.cs  서식 있는 붙여넣기용 클립보드 처리
```

## 현재 프로토타입의 한계 (실제 서비스 전 보완 필요)

- 스타일 분석은 정교한 NLP가 아니라 규칙 기반 통계입니다. "AI 문체 심층 분석" 기능으로 보완할 수 있지만,
  더 정확한 문체 반영을 원하면 기존 글에서 더 많은 발췌를 few-shot으로 넣는 방식으로 고도화할 수 있습니다.
- 사진 자동 배치 기능은 현재 UI/로직이 비활성화되어 있습니다.
- API 키는 세션 중 메모리에만 유지되며 저장하지 않습니다. 필요하다면 Windows
  자격 증명 관리자(Credential Manager) 연동을 추가할 수 있습니다.
- Groq 무료 한도(분당 요청 수, 일 토큰 한도)를 초과하면 자동으로 재시도하지만, 한도가 계속 초과되면
  잠시 후 다시 시도해야 합니다.
